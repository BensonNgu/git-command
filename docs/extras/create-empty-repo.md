# Create Empty GitHub Repository

This guide shows how to create a new empty repository on GitHub.

## 1. Create a New Repository

![GitHub New Repository button]({{ '/assets/images/create-repo-1.png' | relative_url }})

Go to GitHub and click the **New** button at the top of the left sidebar to create a new repository.

## 2. Name Your Repository

![Repository name field]({{ '/assets/images/create-repo-2.png' | relative_url }})

Enter a name for your repository.

## 3. Add a Description

![Repository description field]({{ '/assets/images/create-repo-3.png' | relative_url }})

Optionally, enter a short description explaining the purpose of the repository.

## 4. Configure the Repository

![Repository configuration options]({{ '/assets/images/create-repo-4.png' | relative_url }})

Choose whether the repository should be **Public** or **Private**.

Since we want to create an empty repository, leave the following options unchecked:

- Add a README file
- Add `.gitignore`
- Choose a license

## 5. Create the Repository

![Create repository button]({{ '/assets/images/create-repo-5.png' | relative_url }})

Click the **Create repository** button.

## 6. Get the Repository URL

![GitHub repository URL]({{ '/assets/images/create-repo-6.png' | relative_url }})

After the repository is created, GitHub will display the repository URL.

## 7. Copy the Repository URL

![Copy repository URL button]({{ '/assets/images/create-repo-7.png' | relative_url }})

Click the **Copy** button next to the repository URL.

You can now use this URL to connect your local Git repository to the GitHub repository.
